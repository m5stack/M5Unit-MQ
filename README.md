# Unit MQ

## Overview

### SKU: U199

Unit MQ is a gas detection unit that can be used with different MQ series sensors to determine the concentration of gases in the environment based on the sensor readings. The module integrates an STM32G030F6P6 microcontroller and communicates via the I2C protocol. The default device address is 0x11, which can be configured by the user.
